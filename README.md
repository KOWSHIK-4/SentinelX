# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/KOWSHIK-4/SentinelX.git
```

Install dependencies

```bash
npm install
```

Run backend

```bash
cd backend
npm run dev
```

Run frontend

```bash
cd frontend
npm run dev
```
